\subsection*{1. What the project is}

\textbf{\texttt{sak-guard}} --- a static pre-commit security guardrail for the Python client
and agent layer of Solana applications.

\textbf{The positioning that matters:} every existing Solana security tool observes
the wrong layer. On-chain linters and scanners (Trail of Bits \texttt{solana-lints},
Soleker) inspect contracts and bytecode. Runtime firewalls inspect a transaction
at submission. **Neither sees the Python code where an agent sources a keypair,
misconfigured a commitment level, or passed unvalidated model output into a
transaction sink.** \texttt{sak-guard} operates there, at commit time.

It is framed as the \textbf{static complement to a runtime transaction firewall} ---
not a competitor. The firewall decides whether a transaction may execute;
\texttt{sak-guard} decides whether the code that builds it should be merged.

\subsection*{2. Technical state}

\subsubsection*{The engine}

\texttt{sak\_guard/} --- \texttt{analyzer.py}, \texttt{strategies.py}, \texttt{cli.py}, \texttt{solana.py}, \texttt{\_\_init\_\_.py}.
Pure stdlib, no runtime dependencies, installable as a pre-commit hook that does
not touch the caller's environment.

\textbf{Nine patterns in three families:}

\begin{longtable}{@{}p{0.17	extwidth} p{0.17	extwidth} p{0.17	extwidth} @{}}\toprule
ID & Family & Detects \\
\midrule
PS-SOL-1 (a–d) & Key material & base58/seed literals, 12/24-word mnemonics, \texttt{b58decode} literals bound to key-like names, key names interpolated into f-strings \\
PS-SOL-2a & solders/solana-py misuse & submission with no commitment and no confirmation \\
PS-SOL-2b & " & \texttt{simulate\_transaction} result whose \texttt{.err} is never checked \\
PS-SOL-2c & " & blockhash $\rightarrow$ intervening work $\rightarrow$ send (temporal, heuristic) \\
PS-SOL-3 (a–d) & Inference artefact provenance & unverified model output reaching \texttt{Pubkey()}, \texttt{transfer}, \texttt{send\_transaction}, \texttt{send\_raw\_transaction} \\
\bottomrule\end{longtable}

Every pattern emits \texttt{found} / \texttt{clear} / \texttt{n/a}. Non-Solana input returns \texttt{n/a}
rather than \texttt{clear}, so a clean generic-Python file is never mistaken for a
clean Solana file.

\subsection*{6. Traps learned (do not re-learn these)}

\begin{itemize}
\item \textbf{\texttt{filecontents*} does NOT overwrite an existing \texttt{references.bib}.} A stale
\end{itemize}
  copy silently shadows the embedded block and \texttt{bibtex} drops whatever changed in
  it \textbf{with no warning}. The \texttt{filecontents} package cannot fix it --- it is
  obsolete and defers to the kernel. Use \texttt{build.sh}.
\begin{itemize}
\item \textbf{Zero undefined citations $\neq$ clean compile.} Citations and cross-references are
\end{itemize}
  separate counters. A \texttt{\textbackslash\{\}ref} to an unlabelled equation renders as \texttt{??} while the
  citation count stays 0. Check both.
\begin{itemize}
\item \textbf{Verify the effect, not the write.} A green local check cannot distinguish a
\end{itemize}
  pushed commit from one that never left the machine. Scrub-token $\rightarrow$ push is one
  atomic sequence: set token URL $\rightarrow$ push $\rightarrow$ scrub $\rightarrow$ \textbf{verify from the remote}.
\begin{itemize}
\item \textbf{\texttt{gitignore} does not untrack.} \texttt{git add -A} before writing \texttt{.gitignore}
\end{itemize}
  commits bytecode; use \texttt{git rm -r --cached}.
\begin{itemize}
\item \textbf{A path that does not exist must not exit 0.} An exit code derived from
\end{itemize}
  findings *present* returns success when a path yields no files --- a typo silently
  passes the hook. Assert the exit code for inputs that \textbf{must fail}.
\begin{itemize}
\item \textbf{Metadata verification $\neq$ having read the paper.} Bibliographic facts can be
\end{itemize}
  perfectly resolved while the claim attached to them is unsupported, and author
  lists can be wrong in both directions. Read the abstract at minimum.
\begin{itemize}
\item \textbf{Never fabricate a citation field.} A DOI, venue or year that could not be
\end{itemize}
  resolved is marked for author confirmation, never guessed.
